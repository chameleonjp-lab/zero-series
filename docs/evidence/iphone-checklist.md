# 実iPhone / VoiceOver 確認表

状態: 未実施。クラウドのChromium・WebKit、320/375/390/430px・タッチ模擬、axe自動検査は実iPhone SafariとVoiceOverの合格証拠ではない。ゲームを開始しない確認で足りる項目から実施できる。

記録するもの: 候補完全SHA/source-revision、確認日時、iPhone機種、iOS/Safari版、向き、文字サイズ、VoiceOver有無、合否。個人名・通知・アカウント表示は記録しない。

| 操作 | 合格条件 |
|---|---|
| 縦横で全8カードをスクロール | 1列、画面端の余白、切れた画像/HUD・横スクロール・重なりがない |
| Safariの文字を200%へ拡大、ピンチズーム | 紹介・長い作品名・登録名・スコアが折返され、入口とmodeを操作できる。ズーム禁止なし |
| 入口・mode・再試行へタップ、外部キーボードTab | 44px以上の対象、誤タップしにくい間隔、focusが見える、読み順が自然 |
| FFでイージーを選び、入口へ移動し開始せずSafariで戻る | 直前のscroll位置と選択modeを保持。不要な再読込・重複取得・古いmode結果がない。BFCacheの実有無も記録 |
| 戻った後に明示的な再読込 | 静的紹介と確認済み入口を読める。新文書はdefault mode。版・画像が一致する |
| 低速/機内モード/画像失敗 | 一作品の画像・順位障害でも入口を使える。代替表示、取得失敗、未接続、停止、0件を混同しない |
| VoiceOverで見出し・画像・リンク・mode・状態を順に読む | 作品名が分かるリンク名、画像説明、mode/版が読め、状態通知が重複しすぎずfocusを奪わない |
| 接続後に実順位を載せて再確認 | 最大5行・長い登録名/スコア・同点が読め、版/難易度混在なし。現在は全8未接続のため未実施 |

未接続状態には再試行を表示しない。再試行/画像失敗を強制する確認は、本番データを変更せず検査用候補環境で行う。写真はタイトル画面5件と準備中3件を表示し、実プレイ画面の確認完了とは呼ばない。
